# Windows 自動実行の設定（タスクスケジューラ）

毎日決まった時刻に自動実行する設定です。

## 方法A：コマンドで一発登録（推奨）

1. フォルダ `reins-downloader` を分かりやすい場所に置く（例: `C:\reins-downloader`）
2. 「コマンドプロンプト」を**管理者として実行**で開く
3. 次を貼り付けて実行（毎朝7:00に実行する例。`/st` の時刻と `/tr` のパスは必要に応じて変更）:

```
schtasks /create /tn "REINS自動DL" /tr "C:\reins-downloader\run.bat" /sc daily /st 07:00 /rl HIGHEST
```

登録の確認:
```
schtasks /query /tn "REINS自動DL"
```

削除する場合:
```
schtasks /delete /tn "REINS自動DL" /f
```

## 方法B：画面で設定

1. スタートメニューで「タスク スケジューラ」を開く
2. 右側「基本タスクの作成」をクリック
3. 名前: `REINS自動DL` → 次へ
4. トリガー: 「毎日」→ 開始時刻を指定（例 7:00）→ 次へ
5. 操作: 「プログラムの開始」→ 参照で `run.bat` を選択 → 次へ → 完了

## 注意
- PCが起動している（スリープしていない）必要があります。
- スリープ中でも動かしたい場合は、タスクのプロパティ →「条件」タブで
  「タスクを実行するためにスリープを解除する」にチェックを入れてください。
